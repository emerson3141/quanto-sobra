# quanto-sobra
App financeiro pessoal com 4 telas (Resumo, Lançamentos, Contas, Receitas)
	•	Foco na "sobra projetada" do mês como métrica principal
	•	Suporte a múltiplos meses (duplicar mês anterior, histórico salvo)
	•	Edição inline dos lançamentos, contas e receitas
	•	Dados salvos no localStorage do navegador (por enquanto, sem sincronização entre dispositivos)
